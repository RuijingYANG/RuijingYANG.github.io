https://www.overleaf.com/project/6a43cbacbd56c24076bcb825
Main source file: `Chandler_CV.tex`.

When a requested website update also affects the CV, update the Overleaf source
as part of the same task. Preserve its existing LaTeX template and unrelated
content. Compile and inspect the PDF, then publish the exported PDF at
`files/Ruijing_Yang_CV.pdf`. Do not generate a replacement CV from website data.
If Overleaf access is blocked, report the blocker and keep the existing official
PDF until a verified Overleaf export is available.

Keep teaching course titles, semesters, and display order consistent between
`_teaching/` and the Overleaf CV. Preserve existing course records. Verify the
GitHub Pages deployment and the live downloadable PDF after publishing.
